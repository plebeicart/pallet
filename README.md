# Паллетная Компания

Готовый статический корпоративный сайт на HTML5, CSS3 и Vanilla JavaScript. Сборка, Node.js и npm для запуска не нужны. Работа выполнена в текущем каталоге, без публикации во внешнем хостинге.

## Запуск на Ubuntu

Из каталога проекта:

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080. Остановка сервера: Ctrl+C. Если Python отсутствует: `sudo apt install python3`.

## Файлы

- `index.html` — главная, каталог из шести позиций, услуги, производство, компания, этапы, заявка и контакты.
- `css/style.css` — визуальная система, адаптивность 320–2560+, состояния, reduced motion.
- `js/main.js` — мобильное меню, фильтры, модальные окна, валидация и адаптер отправки.
- `privacy.html` — честное описание обработки данных демонстрационной версии.
- `assets/images/` — локальные фотографии исходного сайта.
- `assets/icons/favicon.svg` — новая монограмма ПК; остальные SVG встроены в HTML.
- `assets/fonts/` — Manrope с кириллицей, веса 400, 700, 800 и лицензия OFL.
- `qa/` — снимки desktop и mobile; `qa/report.md` — результат проверок.

## Реализовано

Sticky header, мобильное меню с Escape и закрытием по внешнему клику, якорная навигация, пять фильтров каталога, модальные заявки с выбранным товаром, подробности шести дополнительных услуг, native dialog с удержанием фокуса и Escape, кнопка наверх, появление блоков при прокрутке, hover и focus, reduced motion. Телефоны и email кликабельны; адрес открывается в Яндекс Картах.

Формы проверяют имя, телефон (10–15 цифр и допустимые символы), обязательное согласие. По умолчанию данные не отправляются. Уведомления выводятся через live region. Backend подготовлен, приём управляется серверным флагом; внешняя аналитика не подключена.

## Подключение заявок

Добавлен FastAPI backend: `POST /api/requests`, SMTP Яндекса по SSL, фиксированный
получатель `vip@xn--80akrarw.com`. Обе существующие формы используют same-origin
API. **Реальные заявки отключены по умолчанию**: `REQUESTS_ENABLED=false`.
До подтверждения юридической готовности не включать приём. В этом режиме
данные формы не отправляются с браузера. Backend дополнительно отклоняет POST.

[Полная инструкция: локальный запуск, контракт API, безопасность, точные команды
для VPS, обновление и откат](docs/requests-deployment.md).
[Результаты проверок](qa/requests-report.md).

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000 --workers 1 --no-proxy-headers --no-access-log
```

Python 3.11+. Секреты передаются через окружение; `.env.example` не содержит
пароля. Для VPS подготовлены `deploy/pallet-api.service` и фрагмент Caddy.
Сервис запускается одним worker; временные лимиты и защита от дублей находятся
в памяти и сбрасываются при перезапуске. Не использовать несколько worker.
Тесты подменяют SMTP и никогда не отправляют настоящую почту.

Сведения ниже о прежнем отсутствии backend и демонстрационном режиме описывают
историю проекта; актуальное управление отправкой приведено выше.
